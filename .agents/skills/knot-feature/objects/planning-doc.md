# 기획서 (참조 객체)

한 문장 책임: 서비스 배경과 푸는 문제를 담은 참조 문서. 기능 요구사항이 일방적으로 참조한다.

| 읽기 | 쓰기 |
| --- | --- |
| 모두 | 유월만. 하네스는 수정 요청을 거부한다. |

## 메시지

- 받는 메시지: 없음. 실행하는 에이전트가 아니다. 입구 스킬도 다른 객체도 이 객체를 부르지 않는다.
- 보내는 메시지: 없음. 기능 요구사항 객체가 이 문서를 직접 읽는다.

## 규칙

- 읽기만 한다. 팀원은 기획서를 고치지 않고, 바꿔야 하면 1차로 거부한 뒤 유월에게 승인받는다.
- 기획서는 이 개발 흐름에서 아예 뺀다. 기능 요구사항이 일방적으로 참조하는 `CLAUDE.md` 같은
  문서이고 수정은 흐름 밖에서 따로 한다.
- 요청이 기획서 수정을 전제로 해야만 성립하면 입구 스킬이 요청을 거부하고 유월에게 컨펌받으라고
  안내한다. 흐름 도중에 어느 객체가 이를 발견하면 `blocked`로 돌아오고 `question`에 유월 승인이
  필요하다고 적는다. 훅이나 루트 Markdown으로 막지 않고 지침으로 거부한다.
